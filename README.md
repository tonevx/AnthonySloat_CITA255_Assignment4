# Assignment 4 — [Live Data and Quest Log]

**Name:** Anthony Sloat

## What it does
The tool gives you a quest log. The user can add quests through three entry items - which will take the title of the quest, the giver of the quest, and the amount of gold you'd earn from completing the quest (represented by 'g'). When you complete a quest, you can click the button and the quest will be removed! Closing and reopening the program will save any work you have done.

## How to run it
Open the .sln file in Visual Studio, set the target to Windows Machine, and press F5.

No known issues at the moment. The program was tested by a classmate, and addition, deletion, and saving/loading of the Quest Log works as intended.
